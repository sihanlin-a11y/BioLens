DNA Replication

Every time a cell divides, it must copy all of its DNA so each daughter cell gets a complete set of genetic instructions. This process — called DNA replication — happens in four key stages. Click each step below.

Study mode:

Step 1: Unwinding

Breaking open the double helix

DNA normally exists as a twisted "double helix" — two strands wound around each other like a spiral staircase. Before copying can begin, this twist must be unzipped.

  • Helicase is an enzyme that travels along the DNA and breaks the weak bonds between the two strands, like unzipping a zipper.
  • This creates a "replication bubble" — an open region with two exposed single strands, each ready to serve as a template.
  • Proteins called SSBPs (single-strand binding proteins) hold the strands apart so they don't snap back together.
💡 Key molecule: Helicase — the "unzipper" of DNA

Step 2: Priming

Setting the starting line

DNA polymerase — the main copying enzyme — cannot start from scratch. It needs a short "starter" sequence to attach to. That starter is called a primer.

  • Primase reads the exposed single strand and builds a short RNA primer (about 10 nucleotides long).
  • The primer marks the exact spot where copying will begin — like placing a bookmark in a book.
  • Each template strand gets its own primer, so both strands can be copied simultaneously.
💡 Key molecule: Primase — writes the "start here" signal

Step 3: Elongation

Building the new strands

This is the main copying phase. DNA Polymerase III attaches to the primer and reads the template strand, adding matching DNA nucleotides one at a time.

  • The rule: A pairs with T, and C pairs with G — DNA polymerase follows this perfectly, letter by letter.
  • The leading strand is built smoothly; the lagging strand is built in short chunks called Okazaki fragments.
  • DNA polymerase also proofreads, detecting and fixing mistakes as it goes.
💡 Key molecule: DNA Polymerase III — the main "copy machine"

Step 4: Finishing

Sealing and proofreading

After elongation, the new DNA strands need to be completed and cleaned up before the cell can use them.

  • DNA Polymerase I removes the RNA primers and fills the gaps with correct DNA nucleotides.
  • DNA Ligase acts like molecular glue, sealing the small nicks between fragments into one continuous strand.
  • The result: two identical double-stranded DNA molecules — each with one original and one new strand. This is semi-conservative replication.
💡 Key molecule: DNA Ligase — the "glue" that seals the new strand
