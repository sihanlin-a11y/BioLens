# BioLens — Hackachusetts Submission

## Project description (concise)

**BioLens turns a biology lecture PDF into organized study notes, a practice
quiz with explanations, an "ask your notes" tutor, and an interactive
visualization — all grounded in the student's own material, and always honest
about what is AI-generated.**

Students waste hours re-reading dense slides, and most "AI study tools" either
hallucinate facts or hide how they work. BioLens is different on both counts:
every AI result is grounded in the uploaded lecture and flags its own
uncertainty, and the app is explicit at all times about whether content is
generated live by Google Gemini, replayed from a saved real run, or a
manually prepared demo example. A clearly labeled **Demo Mode** lets the whole
experience run offline with zero API calls — so the demo is reliable even when
the API is unavailable.

- **Live AI:** Google Gemini via a small Flask backend that keeps the API key
  server-side (never in the frontend).
- **Honest by design:** persistent LIVE/DEMO banner, per-result source labels,
  uncertainty flags, and no fabricated citations.
- **Frontend:** vanilla HTML/CSS/JS, minimalist black-and-white design,
  six languages, interactive SVG phylogenetic trees and flowcharts.

## 3-minute demo outline (target ~2:40)

> Run this entirely in **Demo Mode** for reliability — no backend or key needed.

**0:00–0:20 — Hook & problem**
"Biology students drown in lecture slides, and AI tools often make things up.
BioLens turns your own lecture into study material and is honest about what's
AI and what isn't." Show the homepage.

**0:20–0:35 — Enter Demo Mode**
Click **Switch to Demo** (banner turns amber: "DEMO MODE — no live AI calls"),
then **Load BIO 280 example**. Point out the honest banner.

**0:35–1:15 — AI Notes**
Open **Notes → Generate Smart Notes**. Show the organized topics, key terms,
and takeaways. Point to the label: *"Example study content (manually prepared)
— not generated by AI."* Emphasize: we never dress up hand-written content as
live AI.

**1:15–2:00 — AI Quiz**
Open **Practice → Generate AI Quiz**. Answer one question right and one wrong.
Show the per-option explanations (why the correct answer is right AND why the
wrong one is wrong), the score, and the "concepts to review" list.

**2:00–2:35 — Visualize**
Open **Visualize → Visualize This Lecture**. Show the interactive phylogenetic
tree. Click an internal node to highlight the common ancestor, its descendants,
and sister taxa. Note the honest "common ancestry" explanation.

**2:35–2:40 — Close**
"Live mode does all of this from any uploaded PDF via Gemini; Demo Mode makes
it reliable offline. Built with Kiro, honest about every result." Mention the
six-language toggle if time remains.

## What is live vs. example in the demo

| Shown in demo | Source | Label in UI |
|---|---|---|
| BIO 280 Notes | Manually authored | "Example study content … not generated by AI" |
| BIO 280 Quiz | Manually authored | same |
| BIO 280 Visualization | Manually authored | same |
| Any uploaded PDF in **Live** mode | Google Gemini | "Generated by Google Gemini" |

## Honesty statement

The bundled BIO 280 example content is **written by the team** for a reliable
demo and is labeled as such throughout the UI. It is not presented as live or
saved Gemini output. Live AI features genuinely call Google Gemini when a key
is configured and the project has access.
