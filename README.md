# BioLens 🔬

**Turn your lecture PDFs into organized notes, practice quizzes, and interactive visualizations — grounded in your own material.**

Built for Hackachusetts.

---

## The problem

Biology students drown in dense lecture slides. Re-reading PDFs is slow, generic study tools don't know *your* lecture, and most "AI study apps" either hallucinate facts or hide how they work. BioLens turns a lecture PDF into structured study material that stays faithful to the source — and is honest about what is AI-generated versus saved.

## What BioLens does

Upload a text-based lecture PDF (or paste notes), and BioLens gives you four study tools plus a reliable offline demo:

| Feature | What it does |
|---|---|
| **AI Notes** | Organizes the lecture into topics, key points, definitions, and exam takeaways — grounded only in your text, with uncertainty flagged rather than invented. |
| **AI Quiz** | Generates personalized multiple-choice questions (choose count + difficulty) with explanations for the correct answer *and* why each wrong option is wrong, a score, and a "concepts to review" list. |
| **AI Tutor (Ask AI)** | Answers questions using your lecture as context; falls back to a keyword search of your notes. |
| **Visual Learning** | Generates an interactive visualization from your lecture — phylogenetic trees (click nodes to trace common ancestry), process flowcharts, comparison tables, or labeled diagrams. Includes a built-in DNA Replication demo lesson. |
| **Offline Demo Mode** | Runs the whole app with **zero API calls** using bundled example content — ideal for a public static deployment or when the API is unavailable. Clearly labeled so examples are never mistaken for live AI. |

It also supports six interface/learning languages (English, 简体中文, Español, 한국어, 日本語, Français).

## Live AI vs. demo content (honesty)

BioLens is explicit about this at all times, with a persistent banner and a label on every result:

- **Live mode** — results are generated now via Google Gemini. A green indicator in the bottom banner reads *"LIVE MODE,"* and results are attributed to Gemini.
- **Demo mode** — results come from `demo-data.js` and make **no** API calls. Each snapshot declares its source:
  - `source: "authored"` → **manually written** example content. The UI labels it *"Example study content (manually prepared for this demo) — not generated by AI."* The bundled **BIO 280 — Species, Genes, and Trees** example is authored content.
  - `source: "gemini"` → a **real** earlier Gemini run, captured and saved. The UI labels it *"Saved AI result — captured earlier, not generated just now."*

Manually written examples are **never** attributed to Gemini. Demo Mode makes no network calls.

### Try the demo with no setup
1. Open the site (or `index.html`).
2. Click **Switch to Demo** in the bottom banner.
3. Click **Load BIO 280 example**.
4. Open the Notes, Practice, and Visualize tabs and interact with the example.
No API key, no backend, no PDF upload required.

## Technologies

- **Frontend:** vanilla HTML, CSS, and JavaScript (no framework). Minimalist black-and-white design.
- **PDF extraction:** [PDF.js](https://mozilla.github.io/pdf.js/) (runs in the browser).
- **Backend:** Python + [Flask](https://flask.palletsprojects.com/) — a thin relay that keeps the API key off the frontend.
- **AI model:** [Google Gemini](https://ai.google.dev/) via the official `google-genai` SDK.

## Run it locally

### 1. Start the backend (for live AI)

```bash
cd server
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # then add your key (next section)
python app.py
```

The server runs at `http://localhost:5001`. Leave this terminal open.

### 2. Open the frontend

Open `index.html` in a browser (double-click it, or right-click → Open With → your browser). No build step. The first load needs internet to fetch PDF.js and the Inter font.

> **Demo-only mode:** If you just want to see saved results without the backend, open `index.html` and click **Switch to Demo** in the bottom banner. No server or key required.

## Configure a Gemini API key

1. Get a **free** key at [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) (Google account required, no credit card).
2. Copy the template and add your key:
   ```bash
   cd server
   cp .env.example .env
   ```
3. Open `server/.env` and paste your key:
   ```
   GEMINI_API_KEY=your-key-here
   GEMINI_MODEL=gemini-2.0-flash
   ```
4. Restart the server.

Check it worked: open `http://localhost:5001/api/health?test=1` — you should see `"live_test": "success"`.

> **Security:** `.env` is listed in `.gitignore` and must never be committed. The key stays on your machine; the frontend never sees it. Keys issued today start with `AQ.` (the current format) and are fully supported.

## Deploy the static demo (public HTTPS, no backend)

Demo Mode is pure static files, so you can host it for free on any static host:

**GitHub Pages**
1. Push this repo to GitHub.
2. Repo **Settings → Pages → Build from branch → `main` / root**.
3. Open the published `https://<user>.github.io/<repo>/` URL.
4. Click **Switch to Demo** → **Load BIO 280 example**.

The backend (`server/`) is only needed for *live* AI and is simply ignored by
the static host. No API key is involved in the static demo.

> Other one-click options: Netlify or Vercel (drag the repo folder in, or
> connect the GitHub repo). Any of them serve the files over HTTPS.

## Privacy

- BioLens runs entirely on your machine (or a static host for the demo). There is no account, database, or cloud storage.
- When you use a **live** AI feature, only the lecture text you choose to process is sent to Google Gemini for that request. Review [Google's API terms](https://ai.google.dev/terms) for how they handle data.
- Demo Mode sends nothing anywhere.
- Your API key is stored only in `server/.env` on your computer and is never committed.

## Limitations (honest scope)

- **Text-based PDFs only.** Scanned/image-only slides can't be read (no OCR). Image-heavy slides may produce limited or no results, and BioLens says so rather than inventing content.
- **Free-tier quota.** Gemini's free tier has per-minute and daily limits. The backend retries temporary rate limits with backoff and clearly distinguishes them from an exhausted daily quota. Demo Mode exists precisely for when quota runs out.
- **AI can still err.** Results are grounded in your lecture and flag uncertainty, but should be verified against authoritative sources — this is a study aid, not a reference.
- **Single lecture at a time.** Multi-course libraries and persistence are future work.
- **Visualization quality depends on the lecture.** BioLens picks the most appropriate diagram type from the text; sparse lectures may yield a simpler diagram or an honest "not enough information" message.
